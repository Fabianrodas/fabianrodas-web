Up to version 1.6, every Lumen post stored a single photo or video. For a birthday, that meant twenty nearly identical posts with the same description pasted twenty times.

## What changed

A post is now called a memory and groups up to 30 photos and videos. The description, comments, favorite and tags belong to the whole memory; only each file's details change as you move from one photo to the next.

<Figura kind="lumen-movil" titulo="A memory with twelve photos" texto="The active photo fills the screen, and the thumbnail strip lets you jump between files without leaving the memory." />

## How I solved it

The tricky part was uploading. I wanted the family to pick many files at once without learning a new form, so I kept the same field and added a queue that uploads files three at a time.

```python title="recuerdos.py"
MAX_ARCHIVOS = 30

def crear_recuerdo(usuario, archivos, descripcion):
    if len(archivos) > MAX_ARCHIVOS:
        raise ValueError("Un recuerdo admite hasta 30 archivos")
    recuerdo = Recuerdo(autor=usuario, descripcion=descripcion)
    for orden, archivo in enumerate(archivos):
        recuerdo.medios.append(guardar_medio(archivo, orden))
    return recuerdo
```

<Aviso>The limit lives on the server, not just in the form: if someone tries to upload more files another way, the API answers with a clear error instead of saving half of them.</Aviso>
